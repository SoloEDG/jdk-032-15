# 骨牌造境

## 分岔进入角分路

选中分岔元件后，可在右侧「元件属性 → 进入角分路」设定进入角度分界（默认 45°）以及正面撞击导向哪一侧支路：

- 进入角 `< 分界` 判为**正面撞击**，走设定侧（默认左支路）；
- 进入角 `≥ 分界` 判为**擦边撞击**，走另一侧。

进入角是入射运动方向与分岔分路轴之间的锐角（0° 正面，90° 擦边）。左右支路优先取连线的显式 `side`，否则按终点相对分岔朝向的几何位置判定。

同一次碰撞（`撞击源 -> 分岔`）由碰撞闩锁只按**首次触碰**定路：临界角附近先擦过再反弹撞回、或连续两次触碰产生越过阈值的第二个角度时，只记录后续触碰，路线不会来回切换。

分岔事件会把当次运行的入射角、阈值、判定、导向支路、触碰次数与闩锁状态写入 `event.routing`。回放面板的「分路依据」卡片只读取这份运行时快照，不会用当前属性重新解释旧事件；调整阈值后旧回放保持原方向，重新模拟才对新的传播生效。终点 chips、场景着色与 `run.endpoints` / `reachedTriggerIds` 随所选支路一起更新。

验证：

```sh
npm test          # 24 个用例：阈值两侧近似角、连续两次触碰、擦边回弹、不可变回放、UI 全流程
```

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8032>。端口可通过 `DOMINO_LAB_PORT` 修改。
